# Settings UI — вкладка настроек на дисплее

## Проблема

Флаги CLI (Remote CLI, TerminalCLI, Timesync) управлялись только через CLI-команды
или Serial. Изменить их без подключения к ноде было невозможно.

## Решение

Новая страница `SETTINGS` в `HomeScreen` companion radio. Управление одной кнопкой,
работает на OLED и e-ink дисплеях.

## Навигация (одна кнопка)

| Где | Нажатие | Действие |
|-----|---------|----------|
| Листалка страниц | короткое | следующая страница |
| Листалка страниц | долгое на Settings | войти в редактирование |
| Редактирование | короткое | следующий пункт (курсор вниз) |
| Редактирование | долгое | изменить значение / активировать |
| Редактирование | двойное | выйти в листалку |

Пункт `Back` в конце списка — выход через долгое нажатие.

## Пункты настроек

### CLI Chat

Управляет тем, какие режимы CLI активны.

| Значение | Remote CLI (PM+PIN) | TerminalCLI (канал) |
|----------|---------------------|---------------------|
| `C+P` | ✓ | ✓ |
| `cht` | — | ✓ |
| `PM` | ✓ | — |
| `OFF` | — | — |

> Изменение runtime-флаг, не сохраняется при перезагрузке.
> При `OFF` или `cht` — PM с PIN-кодом игнорируются.
> Канал TerminalCLI из списка каналов не удаляется (только CLI-команда `set terminal.cli off` делает это).

### CLI PIN

Показывает текущий PIN-код на 3 секунды, затем скрывает (`****`).

PIN нужен для Remote CLI (Approach 1): отправляешь PM `<PIN> <команда>`.
PIN выводится также в Serial при загрузке: `CLI PIN: A1B2C3D4`.

### Timesync

Управляет источниками автоматической синхронизации времени.

| Значение | Адверты | Таймстемпы сообщений |
|----------|---------|----------------------|
| `a+g` | ✓ | ✓ |
| `adv` | ✓ | — |
| `gps` | — | — (только GPS-железо) |

> `gps` отключает сетевую синхронизацию полностью — кворумный буфер не пополняется.
> GPS hardware sync (`gps sync` CLI) доступен независимо от этого флага.

## Отображение на экране

**Вид страницы в листалке** (не в редактировании):
```
──── Settings ────
  long press to enter
```

**Режим редактирования** (128×64 OLED):
```
     Settings
> CLI Chat   C+P
  CLI PIN    ****
  Timesync   a+g
  Back
```

Курсор `>` отмечает текущий выбранный пункт.

## Детали реализации

- **Без `WITH_COMPANION_CLI`**: страница компилируется, показывает только `Back`.
- **`_in_settings`** — bool-флаг режима редактирования в `HomeScreen`; сбрасывается при выходе.
- **PIN reveal**: `render()` возвращает `remaining_ms` пока PIN виден → экран обновляется ровно в момент истечения таймера.
- **Поглощение кнопок**: в режиме редактирования все клавиши обрабатываются до стандартной навигации страниц (early return).

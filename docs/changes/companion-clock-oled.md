# CLOCK page на OLED + PM inline + настройки димминга

## Проблема

Страница CLOCK была доступна только на e-ink дисплеях. OLED дисплеи (128×64)
не могли отображать большие часы — шрифт размером 8× (240px) шире экрана.
PM inline preview также работал только на e-ink.

## Решение

### CLOCK на OLED

На OLED используется `setTextSize(3)` — символы 18×24px, "HH:MM" = 90px,
влезает в 128px с запасом. Ниже часов выводится дата и источник синхронизации.

```
     14:35
  Mon 04 May
   advert +2s
```

На e-ink рендер не изменился (setTextSize(8), как прежде).

### PM inline на CLOCK (OLED и e-ink)

При получении PM на странице CLOCK сообщение показывается поверх часов:
заголовок с именем отправителя, разделитель, текст с переносом строк.
KEY_NEXT закрывает PM и возвращает к часам.

Управляется настройкой **PM CLOK** (см. ниже).

## Новые настройки (страница Settings)

### PM CLOK `[all / PM]`

Поведение при получении сообщения на странице CLOCK.

| Значение | Поведение |
|----------|-----------|
| `all` | Любое сообщение переключает на общий чат (msg_preview) |
| `PM` *(по умолчанию)* | PM показывается inline; канальные сообщения — в очередь без переключения |

### CLOK DIM `[AOF / USB / AON]`

Управление гашением OLED экрана.

| Значение | Поведение |
|----------|-----------|
| `AOF` *(по умолчанию)* | Стандартное гашение через AUTO_OFF_MILLIS (15 сек без активности) |
| `USB` | USB подключён → таймер постоянно сдвигается, экран не гаснет; на батарее → как AOF. Режим не сбрасывается при отключении USB |
| `AON` | На вкладке CLOCK таймер постоянно сдвигается, экран не гаснет; на других вкладках → как AOF |

USB детектируется через напряжение батареи: `getBattMilliVolts() == 0 || > 4150mV`.

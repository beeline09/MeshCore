# 0002 — Экраны UI: шум/SNR, датчики INA + ETA, карусель репитера, «экран при зарядке»

Ревизия 3 — СОГЛАСОВАНА владельцем 2026-10-17 («спека ок»): OQ-1..7 отвечены (§7), INA-таблица клиента без SP с видимыми точками карусели (FR-11/12).

## 1. Обзор

Четыре направления работ поверх spec 0001 (фазы 1/1b завершены):

1. Настройка «держать экран включенным при зарядке» — на сайте и в UI обеих
   прошивок (клиент). Значение по умолчанию — как сейчас: включено.
2. Новый экран карусели клиента: график шума и SNR.
3. Новый экран карусели клиента: таблица каналов INA3221 + ETA.
4. Карусель для репитера (сейчас — один статический экран): радио → соседи →
   шум/SNR → датчики INA + ETA → настройки.

Этапы: (1) юг-клиент + сайт, (2) юг-репитер, (3) официалка-клиент,
(4) официалка-репитер. Правила прежние: официалка — только оверлеи
варианта; на юге допускаются точечные согласованные правки ядра.

## 2. Текущее состояние (разведка)

- **График шума MacMillan25** (PR #35, ветка feat/darktec-e22p, коммит в
  ui-new/UITask.cpp): кольцевой буфер 64 сэмпла `radio_driver.getNoiseFloor()`
  (ядро пересчитывает значение раз в `NOISE_FLOOR_CALIB_INTERVAL` = 2000 мс и
  держит кэш — чтение бесплатное), сглаживание средним по 3 точкам,
  автоскейл по min/max сглаженной серии (минимальный размах 8), трасса из
  64 столбцов по 2 px (соседние столбцы соединяются заливкой), скорость
  сэмплирования 100/250/500/1000 мс, `render()` возвращает интервал
  сэмплирования (перерисовка синхронна сэмплингу), экран удерживает
  подсветку (авто-офф не гасит).
- **SNR**: `radio_driver.getLastSNR()` — SNR последнего принятого пакета;
  между приёмами значение не меняется (график будет «ступенчатым»).
- **KEEP_DISPLAY_ON_USB** (юг): флаг сборки; в core-UITask продлевает
  `_auto_off`, пока `board.isExternalPowered()`; `DarktecDisplay::isOn()`
  (вариант) будит OLED при старте зарядки. Официалка — тот же паттерн.
- **Дисплей**: 128×64, шрифт 6×8 (size 1). API: fillRect/drawRect/drawXbm/
  getTextWidth/drawTextCentered/drawTextRightAlign; setPixel/fillTriangle/
  roundRect в API НЕТ — треугольники рисуются строками fillRect,
  «скругление» — срез 1px углов цветом фона.
- **Репитер** (юг): `examples/simple_repeater/UITask.cpp` — 152 строки,
  один статический экран параметров радио. Официалка — аналогично.
  env'ы репитера используют `DISPLAY_CLASS=SSD1306Display`.
- **Хранение**: `/darktec.prefs` (spec 0001) имеет 6 резервных байт —
  новые настройки кладём туда, формат провода НЕ меняется (старые
  прошивки резерв игнорируют, файл совместим в обе стороны).

## 3. User stories

- US-1: держать экран включенным при зарядке — но уметь выключить, если
  жалко панель (OLED выгорает).
- US-2: видеть график шума/SNR в эфире, переключать режим и скорость
  прямо на устройстве.
- US-3: видеть токи/напряжения всех трёх ветвей питания и оценку времени
  до разряда/заряда.
- US-4: на репитере — листать страницы, видеть соседей и шум, настраивать
  без приложения.

## 4. Функциональные требования

### Настройка «экран при зарядке»

- **FR-1.** Новая настройка: держать экран всегда включенным, пока идёт
  зарядка. Значения on/off, **по умолчанию on** (текущее поведение).
- **FR-2.** Хранение: байт 0 резерва `/darktec.prefs` (`keep_display_chg`:
  0x00 = on (дефолт, совпадает с нулями старых файлов), 0x01 = off;
  sanitize приводит к {0,1}). Формат провода и версия файла не меняются.
- **FR-3.** Механика (обе прошивки, клиент): без правок ядра — в
  `DarktecDisplay` (вариант): `turnOff()` при зарядке и включённой
  настройке — no-op; авто-пробуждение при старте зарядки (`isOn()`)
  гэйтится той же настройкой. Официальная — тот же класс уже в env'ах.
- **FR-4.** UI: пункт на странице Darktec (обе прошивки): название
  **«Screen on chg»** (12 симв., помещается), значения On/Off. Список
  пунктов страницы: Capacity, Batt type, Cells, Radio mod, Charge,
  **Screen on chg**, Back (7 строк). Юг: используется скролл настроек
  (6 строк видно). Официалка: шаг строк 7 px, y0=14 — 7 строк ровно
  помещаются.
- **FR-5.** Сайт: чекбокс **«Держать экран всегда включенным при зарядке»**
  (дефолт: включен) → on-demand флаг `-DDARKTEC_KEEP_DISPLAY_CHG=0` когда
  выключен (при включённом флаг не ставится — дефолт), параметр issue-блока
  `keep_display_chg=1|0`, токен имени файла `__kdc0` (только когда off),
  workflow main + оба скрипта (юг/официалка) передают флаг в DEFS_H.

### Экран «Шум и SNR» (клиент)

- **FR-6.** Новая страница карусели (после Discovery, перед Settings/Darktec
  и выключением). Внизу — одна строка значений: слева
  **`NF: -105dBm`**, справа **`SNR: 12.5dB`**. Полное слово «NoiseFloor»
  на 128 px не помещается (21 символ на строку) — используем компактные
  подписи (OQ-1).
- **FR-7.** Всё место между шапкой (точки-индикатор страниц) и строкой
  значений занимает график: 64 столбца × 2 px, трасса со соединением
  столбцов, сглаживание 3 точки, автоскейл min/max (мин. размах 8) —
  по Макмиллану.
- **FR-8.** Долгое нажатие переключает режим графика Noise ↔ SNR.
  Выбранный режим подсвечивается **инверсией**: белая заливка блока
  подписи + чёрный текст; «скругление» — срез 1px углов цветом фона
  (best effort, OQ-7).
- **FR-9.** Тройное нажатие циклит скорость обновления
  **100 → 250 → 500 → 1000 мс** (как у Макмиллана), общая для обоих
  графиков; хранится в байте 1 резерва `/darktec.prefs` (переживает
  перезашивку). `render()` возвращает текущий интервал (перерисовка
  синхронна сэмплингу). На этом экране авто-гашение дисплея не срабатывает.
- **FR-10.** SNR-график: сэмплы `getLastSNR()` тем же тикером; между
  приёмами пакетов значение держится (ступеньки) — принимается (OQ-6).
  У SNR — один десятичный знак.

### Экран «Датчики INA3221 + ETA» (клиент)

- **FR-11.** Новая страница карусели. Таблица с рамками (drawRect +
  разделитель под шапкой): колонки — имя канала, Volt, Curr, P.
  Каналы INA3221: CH1 = SP (солнечная панель), CH2 = **DC**
  (DC/Type-C), CH3 = **Bat**. Значения: вольты — 2 знака, ток — 3 знака
  (мА-разрешение INA), мощность — до тысячных ватта с обрезкой хвостовых
  нулей (`0.4W`, `0.084W`). Читается напрямую из INA3221 ~1 Гц.
  **У клиента SP не выводится** (клиенту солнечная панель не нужна):
  строки — шапка + DC + Bat. У репитера — все три канала, включая SP.
- **FR-12.** Размещение (128×64, расчёт). Шапка с именем ноды и батареей
  ОСТАЁТСЯ (12 px), карусель не отключается — экран листается как все.
  LED-точка активности LoRa (statusDot в DarktecDisplay) НЕ затрагивается.
  **Клиент** (2 строки каналов): точки-индикатор страниц карусели — ВИДНЫ;
  таблица с y≈20 (шапка + DC + Bat), строки крупнее — до 10–11 px
  (точная высота — на устройстве), отступ 1 px, строка ETA внизу —
  всё помещается с запасом. **Репитер** (3 строки, с SP): точки на этой
  странице скрываются (приём уже обкатан на странице настроек) — таблица
  38 px + 1 px + ETA 8 px = 59 px из 64.
- **FR-13.** Под таблицей (отступ 1 px) — **ETA**: оценка времени до
  разряда/заряда, формат `ETA 8h32m` (часы+минуты; >99 ч — `>99h`).
  Перед ETA — индикатор направления (OQ-4): рисованный мини-треугольник
  (5 px, строками fillRect): вверх = заряжается, вниз = разряжается
  (альтернатива владельцу — ASCII `+`/`-`).
- **FR-14.** Формула ETA v1 (OQ-3): разряд — оставшийся заряд
  (SOC% × ёмкость) / средний ток батареи (INA CH3, EMA ~10 с);
  заряд — остаток до полного / номинальный ток заряда (CC-приближение,
  CV-хвост удлиняет реальное время; помечаем `≈`). SOC — из модели
  spec 0001. При |I| < 10 мА в разряде — `ETA --`.

### Карусель репитера

- **FR-15.** Репитер получает карусель страниц (юг и официалка). UI —
  **новый оверлей варианта** `variants/darktec/repeater_ui/UITask.cpp`
  (подмена `examples/simple_repeater/UITask.cpp` фильтром в env'ах
  репитера — паттерн companion_ui; правок ядра ноль).
- **FR-16.** Страница 1 — параметры радио: как сейчас.
- **FR-17.** Страница 2 — соседи: таблица/список соседей, сортировка по
  убыванию SNR; имя (если известно) + SNR. Долгое нажатие — послать
  запрос поиска соседей и пополнить список; тройное — очистить список и
  послать запрос заново; одинарное/двойное — листают карусель.
  Источник данных — таблица услышанных соседей (по образцу
  putNeighbour/NeighbourInfo Макмиллана: id/имя/последний SNR/время),
  запрос — стандартный discovery-пакет (как Discovery у компаньона).
- **FR-18.** Страница 3 — шум и SNR: в точности клиентский экран FR-6..10.
- **FR-19.** Страница 4 — датчики INA + ETA: в точности клиентский экран
  FR-11..14. SOC-модель, INA3221 и ETA доступны на репитере автоматически —
  env'ы репитера собирают тот же вариант Darktec (DarktecBoard/профиль).
- **FR-20.** Страница 5 — настройки:
  - официалка: только папка **[ Darktec ]** (та же, что у компаньона —
    6 пунктов + Back; механика из spec 0001 фазы 1b);
  - юг: пункты репитера, актуальные репитеру — `[ Advert ]` (отправить
    маяк) + `[ Darktec ]`; страница — обычная страница карусели, без
    Exit (OQ-5).
- **FR-21.** Навигация карусели репитера — жестами платы: клик —
  следующая страница, двойной — предыдущая, долгое/тройное — действия
  страницы. На страницах-меню (настройки) клик/двойной двигают курсор
  (как на юге), карусель — со строки выхода/по Escape-строке.

## 5. Нефункциональные

- Экран 128×64, шрифт 6×8; все новые строки — английские (правило UI).
- Все новые экраны и пункты — только для варианта Darktec (стражи
  `DARKTEC`/`__has_include`, оверлеи); чужие платы не затрагиваются.
- Чтение INA — недорогое (I2C ~1 Гц только на видимой странице).
- Graph sampling не трогает радио (кэш ядра).

## 9. Критерии приёмки

- **AC-1.** Настройка «экран при зарядке»: off → экран гаснет при зарядке
  по авто-офф; on (дефолт) → горит. Переживает перезашивку (файл).
- **AC-2.** On-demand с выключенной настройкой собирается с токеном
  `__kdc0`, дефолт файла — off.
- **AC-3.** Шум-экран: график живой, NF/SNR переключаются долгим, выбранное
  инвертировано, тройной меняет скорость (видно по плотности графика),
  скорость переживает перезашивку.
- **AC-4.** Экран INA: клиент — DC и Bat; репитер — SP, DC, Bat; значения
  V/I/P вменяемые (сверить с телеметрией), рамки таблицы, нули в P
  обрезаны; у клиента точки карусели видны.
- **AC-5.** ETA: направление и время правдоподобны (при зарядке растёт
  время-до-полного по мере SOC; при разряде — время-до-пустого падает).
- **AC-6.** Репитер: карусель 5 страниц листается; соседи находятся и
  сортируются по SNR; тройной очищает и ищет заново; шум/SNR и INA+ETA
  работают как у клиента; настройки репитера/официалки открываются и
  сохраняются.
- **AC-7.** Чужие варианты (Heltec и др.) собираются — новые экраны им не
  достаются (стражи/оверлеи).
- **AC-8.** CI обеих веток зелёные; сайт-пайплайн принимает новый флаг.

# 0002 — План реализации

Спека: spec.md (рев. 2, согласована). Задачи: tasks.md.

## Этап 1. Юг-клиент + сайт (FR-1..14, FR-22)

1. **Хранение (D-1)**: `DarktecPrefsFormat.h` — доступ к байтам резерва:
   `keep_display_chg` (байт 0: 0=on, 1=off; sanitize клампит к {0,1}) и
   `noise_speed_idx` (байт 1: 0..3; sanitize клампит к 0..3); поле в
   `Settings` + сериализация в существующие резервные байты (версия
   провода 1 не меняется). `buildFlagDefaults()`: `DARKTEC_KEEP_DISPLAY_CHG`
   (0/1, дефолт 1) → keep_display_chg. Новые валидируемые флаги —
   не нужны (дефолт единственный).
2. **DarktecDisplay (D-2)**: `turnOff()` — no-op при зарядке и
   keep_display_chg=on; `isOn()` — авто-пробуждение при старте зарядки
   гэйтится тем же флагом. Чтение — раз в секунду из кэша prefs.
3. **UI настроек Darktec (юг)**: пункт **«Screen on chg»** (On/Off) между
   Charge и Back (страница станет 7 строк; скролл южных настроек уже
   есть). Правка/чтение — через `DarktecPrefs::get()/save()`.
4. **Экран «Шум и SNR»**: страница `NOISE` в карусели юга (страж
   UI_DARKTEC_SETTINGS); буфер 64, сэмплинг из `radio_driver.getNoiseFloor()`
   /`getLastSNR()`, сглаживание 3 точки, автоскейл (мин. размах 8), трасса
   64×2 px; низ: `NF: …dBm` слева / `SNR: …dB` справа, выбранный блок —
   инверсия (fillRect + срез 1 px углов); долгое — NF↔SNR, тройное —
   скорость (100/250/500/1000, дефолт 500 → /darktec.prefs); render()
   возвращает интервал сэмплинга; авто-офф не гасит (страница продлевает
   `_auto_off`, как CLOCK-страницы делают своими механизмами — точку
   интеграции смотрим в коде).
5. **Экран «INA + ETA»**: страница `INA` (страж); таблица с рамками
   (drawRect + линия под шапкой), чтение INA3221 напрямую (bus voltage +
   current). Клиент: строки шапка + DC + Bat (SP не выводится), точки
   карусели видны, строки до 10–11 px; ETA по FR-14 (SOC из
   DarktecPowerState, ток Bat — EMA, номинал заряда из prefs),
   треугольник направления — строки fillRect.
6. **Сайт**: чекбокс «Держать экран всегда включенным при зарядке»
   (Питание, дефолт on) → `keep_display_chg` в issue-блоке, токен
   `__kdc0` (только off), `needsCustomBuild` учитывает; workflow main —
   input/parse/env `keep_display_chg`; оба скрипта — DEFS_H
   `-DDARKTEC_KEEP_DISPLAY_CHG` + токен имени. Имена сайт↔скрипты сверить.
7. **Проверки**: сборка Darktec_companion_radio_ble + Heltec_t114 (страж),
   native-тесты (формат: новые байта резерва), прошивка на ноду.

## Этап 2. Юг-репитер (FR-15..21)

1. Оверлей `variants/darktec/repeater_ui/UITask.cpp` (подмена
   `examples/simple_repeater/UITask.cpp` в env'ах Darktec_repeater*);
   env'ы репитера → `DISPLAY_CLASS=DarktecDisplay`.
2. Каркас карусели (5 страниц) + страница 1 (радио — перенос текущего
   рендера).
3. Страница «Соседи»: трекер услышанных соседей (по образцу
   putNeighbour/NeighbourInfo Макмиллана; точка врезки — приём пакета в
   оверлейном MyMesh, если понадобится — отдельный оверлей MyMesh.h),
   сортировка по SNR; долгое — discovery-запрос + пополнение; тройное —
   очистка + новый запрос.
4. Страницы «Шум/SNR» и «INA+ETA» — переиспользование кода этапа 1
   (общие хелперы вынести в вариантный заголовок, напр.
   `variants/darktec/DarktecScreens.h`); в INA-таблице репитера — все
   три канала (SP/DC/Bat), точки на этой странице скрыты.
5. Страница «Настройки»: `[ Advert ]` (отправить маяк) + `[ Darktec ]`
   (папка из 0001); страница — страница карусели (клик/двойной листают,
   долгое — действие), без Exit.
6. Сборка Darktec_repeater (+bridge env), прошивка при доступности платы.

## Этап 4. Официалка-репитер (FR-15..21)

1. Оверлей `variants/darktec/repeater_ui/` в ветке dev-darktec (env'ы
   репитера официалки; MyMesh репитера официалки может отличаться —

2. Сборка Darktec_repeater (dev), приёмка.

## Риски

- Теснота INA-таблицы на 64 px — запасной ход: шапка таблицы 8 px
  (FR-12); крайний случай — без строки заголовка колонок.
- Discovery на репитере: если у простого репитера нет API компаньона
  (createControlData/sendZeroHop) — запрос соседей собирается сырым
  пакетом (как у Макмиллана REQ_TYPE_GET_NEIGHBOURS), точка врезки —
  оверлей MyMesh.
- Авто-офф на noise-странице юга: продление `_auto_off` — приватное
  поле UITask; если не достать — страница возвращает короткий интервал
  рендера, а гашение проверяет активность страницы через новый публичный
  метод (правка ядра юга — согласованный файл).
